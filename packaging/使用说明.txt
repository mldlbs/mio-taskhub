mio-taskhub 任务中心 · 使用说明（无需安装 Python）
============================================

【一】怎么启动
  1. 双击运行【mio-taskhub.exe】
  2. 稍等 1~2 秒，浏览器会自动打开任务看板
  3. 如果没自动打开，手动在浏览器输入： http://127.0.0.1:48620

【二】人怎么看板（可选，不配也行）
  - 看板分 6 列：待处理 → 已领取 → 进行中 → 已完成 → 失败
  - 点【创建任务】填标题、优先级、预估耗时 → 提交
  - 拖拽卡片可改变任务状态，页面实时刷新
  - 说明：面板只是给"人"看的，真正领活干活的是 AI 助手（见【三】）

【三】让 AI 助手自动干活 ★核心★
  1. 保持【mio-taskhub.exe】在运行
  2. 双击【setup-agent.bat】一键配置（只需做一次）
     它会自动识别你装了的 agent（opencode / claude code / codex / workbuddy）
     并全部配好
  3. 重启对应的 agent，然后在对话里说：
     “使用 mio-taskhub：先注册，然后领取任务并执行”
  4. 助手会自动：注册 → 领任务 → 做任务 → 上报进度 → 交结果

【四】浮动任务中心面板（可选）
  - 想边工作边看任务进度？双击【mio-taskhub-widget.exe】
  - 会出现一个置顶的迷你任务看板窗口，随时瞄一眼
  - 可拖拽、可缩放；关闭窗口即退出面板（不影响 mio-taskhub.exe 主服务）
  - 前提：【mio-taskhub.exe】必须已在运行

【五】常见问题
  Q: 双击后弹出「端口 48620 已被占用」？
  A: 说明任务中心可能已经在运行。点确定即可，浏览器会自动打开已有看板，
     不需要重复启动。

  Q: 双击后什么提示都没有 / 浏览器没打开？
  A: 说明 48620 被其他程序占用了。在解压文件夹里新建文本【启动8081.bat】，
     写入一行： set MIO_TASKHUB_PORT=8081& start mio-taskhub.exe
     保存后双击这个 bat 启动，浏览器访问 http://127.0.0.1:8081

  Q: 出了别的问题？
  A: 打开 C:\Users\你的用户名\.mio_taskhub\ 文件夹，
     把 runtime.log / console.log 内容发给技术支持即可定位。

  Q: 数据存在哪里？
  A: 存在你自己电脑的 C:\Users\你的用户名\.mio_taskhub\taskhub.db
     换电脑前把这个文件复制走即可备份，换到新电脑后放到同位置。

  Q: 需要联网吗？
  A: 不需要，纯本机使用。
