Why Mio-TaskHub

Agents don't talk to each other.

Each agent is an island. It doesn't know what others are doing, can't share progress, and won't retry on failure.

Without

Manual coordination

  • Switch between terminals, copy-paste task descriptions
  • No visibility into who's doing what
  • Agent crashes → task lost → manual re-run
  • Multiple agents edit the same file → conflicts
  • No structure from idea to execution
With Mio-TaskHub

Automated orchestration

  • One shared queue, agents auto-claim tasks
  • Real-time kanban: who, what, progress, health
  • Heartbeat + auto-retry on failure
  • Dependency ordering prevents conflicts
  • Idea → discussion → tasks → execution, fully tracked
Capabilities

Built for multi-agent workflows.

Task State Machine
7-stage pipeline: brainstorming → design → planning → ready → implementing → review → done. Each stage has entry conditions and required deliverables.
Agent Scheduling
Register → claim → heartbeat → submit. Priority + affinity-based assignment. Timeout auto-reclaim. Agent type matching with fallback.
Dependency Graph
depends_on arrays with cycle detection. Tasks auto-unblock when prerequisites complete. Full graph and sub-graph queries.
Idea Workspace
Record → ferment → review → break down into tasks. Version history. ADR auto-projection to Git repos.
MCP Native
26 MCP tools. Any MCP-compatible agent (opencode, Claude Code, Codex, Hermes) connects with zero adaptation.
Monitoring
Built-in dashboard: CPU/memory/threads/DB pool. 24 alert rules. OpenTelemetry tracing. Structured log query.
Night Runner
Config-driven overnight execution. Spawn agent processes across time windows. Schedule tasks, check results in the morning.
Single Binary
PyInstaller EXE + SQLite file. No Docker, no Node.js, no external database. Run anywhere.

Why Not Just ChatGPT

Not another AI tool.

Mio-TaskHub doesn't write code. It orchestrates the agents that do.

Orchestration Not a TODO list

TODO tools track "what to do." Mio-TaskHub tracks "who's doing it, how far along, and whether they're still alive" — with heartbeats, auto-retry, and priority scheduling.

Multi-agent Not single-agent

ChatGPT serves one user, one task. Mio-TaskHub lets opencode write while Claude Code tests while Codex refactors — all sharing one queue.

Local Not cloud

SQLite file, single EXE. Data stays on your machine. No accounts, no API keys, no external services.

MCP Not proprietary

Open MCP protocol. Any compatible agent connects directly. No vendor lock-in.

Start in 3 commands

Clone, install, run. No configuration needed.

git clone https://github.com/mldlbs/mio-taskhub && pip install -e .
