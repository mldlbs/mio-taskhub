## 文档信息与范围

本次变更**只发生在前端渲染层**，后端代码路径 **0 改动**。因此本文档的「新增契约」不是 HTTP 接口，而是**客户端偏好契约**（localStorage + DOM class），它是本次唯一对调用方可见的行为变化。

**明确不含**：

- 不含任何 REST 接口的**新增、修改或废弃**。
- 不含鉴权、权限模型、错误码语义的变化。
- 不含全量接口清单（hub 共 157 个 REST 路由，不在本文档范围）。
- 不含前端组件库的对外 API（`motion.js` 是内部模块，不对外承诺）。

**变更摘要**：

| 编号 | 变更 | 契约兼容性 |
|---|---|---|
| C-1 | 新增客户端偏好：`localStorage['MIO_MOTION']` = `'on'` \| `'off'`，**无键 = 关闭** | 新增，无历史包袱 |
| C-2 | 偏好作用于 `document.documentElement` 的 `no-anim` class | 新增 |
| C-3 | 所有 HTTP 接口的请求/响应/错误码**一律不变** | 完全兼容 |

## 环境与基础地址

路径前缀 `/api/v1` 由应用自身挂载，不经网关，不会被剥离或重写。

## 认证与鉴权

- **无认证**：本地单用户服务，不校验 token/cookie，不存在 401 态。
- 客户端偏好契约同样**不含任何凭据**：偏好只存于浏览器本地 profile（localStorage），不上传服务端、不跨设备同步。
- 403 表示「已识别调用方但越权」；本次涉及的读取接口不产生 403。

## 通用响应结构

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `detail` | string \| object | 失败时必填 | 失败详情；对象形态含 `code` 与 `message` |
| `version` | string | `update/status` 成功时必填 | 当前版本号 |
| `latest` | string \| null | `update/status` 成功时必填 | 可更新到的最新版本；无更新时为 null |
| `pid` | int | `process/info` 成功时必填 | 进程号 |
| `uptime_seconds` | number | `process/info` 成功时必填 | 运行时长（秒） |
| `memory_rss_mb` | number \| null | `process/info` 成功时必填 | 内存 RSS（MB） |
| `threads` | int \| null | `process/info` 成功时必填 | 线程数 |

- `data` 为 `null` 与 `data` 为 `{}` 语义不同（前者=查询成功但无实体，后者=实体存在但字段为空）。
- 本次涉及的接口**不返回裸数组**，也不返回二进制。

## 统一错误码

| HTTP | 业务码 | 含义 | 触发条件 | 本次是否变化 |
|---|---|---|---|---|
| 404 | — | 资源不存在 | 路径不匹配 | **不变** |
| 409 | `policy_risk_high` | 危险操作需确认 | 破坏性操作命中历史风险策略 | **不变** |
| 500 | — | 内部错误 | 未预期异常 | **不变** |

> 本次**不新增任何错误码**，也不修改任何既有错误码。客户端偏好读写**不产生任何 HTTP 请求**，因此没有错误路径。

## 字段命名与类型规范

- 命名风格：snake_case；布尔用 `is_` 前缀；ID 为 8 位十六进制字符串。
- 反例：`latestVersion`、`IsDone`、`update-status` 一律不用。
- 「字段缺失」与「显式 null」语义不同：`latest` 为 null 表示「无新版本」，不是「未查询」。
- 计数类字段一律整数，不返回字符串。
- **客户端偏好键名**：`MIO_MOTION`（全大写 + 下划线），与既有 `MIO_*` 系列键风格一致。

## 幂等性与重试

| 对象 | 幂等 | 重复调用返回 |
|---|---|---|
| `localStorage['MIO_MOTION']` 写入 | 幂等（同值覆盖） | 同一最终状态 |
| `GET /update/status` | 幂等（只读） | 当前快照 |
| `GET /process/info` | 幂等（只读） | 当前快照 |

- **可安全重试**：全部 GET 与偏好写入。
- **退避策略**：偏好写入无网络交互，失败时静默回落默认值。

## 接口清单

| Method | Path | 用途 | 权限 | 幂等 | 限流 | 关联状态 | 本次变化 |
|---|---|---|---|---|---|---|---|
| GET | `/api/v1/update/status` | 设置页读取版本状态 | 无（本地） | 是 | 不限流 | 任意 | **不变**（动效开关与其同处一个设置页） |
| GET | `/api/v1/process/info` | 设置页读取运行信息（PID/运行时长/内存/线程） | 无（本地） | 是 | 不限流 | 任意 | **不变** |

> 设置页另有 4 个写接口（`update/check`、`update/download`、`update/apply`、`update/dismiss`）——**本次完全不涉及**，其契约不在本文档范围。

## 接口明细

### GET /api/v1/update/status

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认 | 约束 | 示例 |
|---|---|---|---|---|---|---|
| （无） | — | — | — | — | 本接口无查询参数 | — |

#### 响应字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `version` | string | 是 | 当前运行版本 |
| `latest` | string \| null | 是 | 可更新的最新版本；无更新为 null |
| `update_available` | bool | 是 | 是否有可用更新 |
| `notes` | string | 否 | 版本说明 |

#### 错误码

| HTTP | 业务码 | 含义 | 处理建议 |
|---|---|---|---|
| 500 | — | 内部错误 | 看服务端日志 |

#### 示例

```json
{ "version": "0.8.0", "latest": null, "update_available": false, "notes": "" }
```

### 客户端偏好契约 · MIO_MOTION（非 HTTP）

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认 | 约束 | 示例 |
|---|---|---|---|---|---|---|
| `MIO_MOTION` | `localStorage` | string | 否 | 关闭（无键） | 只能取 `'on'` / `'off'`；其他值按默认处理 | `"off"` |

#### 响应字段

| 字段 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `no-anim` | `document.documentElement.classList` | class | 动效关闭时必填 | 存在即表示持续动画被停用；不存在表示动效开启 |
| 持续动画 | CSS | — | — | `animation-duration: 0.01ms` + `animation-iteration-count: 1` |
| 过渡效果 | CSS | — | — | **不关闭**（事件驱动，无常驻开销） |

#### 错误码

| HTTP | 业务码 | 含义 | 处理建议 |
|---|---|---|---|
| — | — | localStorage 不可用（隐私模式） | 静默回落默认（关闭），不影响功能 |

#### 示例

```js
// 关闭动效（设置页开关）
localStorage.setItem('MIO_MOTION', 'off')
document.documentElement.classList.add('no-anim')
// → <html class="no-anim">
```

## 分页

本次涉及的读取接口**均不分页**，返回单个对象。

## 时间 / 数值 / 空值约定

- 时间：`uptime_seconds` 为整数秒；`latest` 为版本字符串。
- 数值：`pid`、`threads`、`memory_rss_mb` 为整数/浮点，均 ≥ 0。
- 空值：`latest` 无更新时为 `null`；`memory_rss_mb`/`threads` 不可得时为 `null`（**不是 0**）。

## 枚举全集

| 枚举 | 取值 | 含义 | 出现位置 |
|---|---|---|---|
| `MIO_MOTION` | `on` / `off` | 动效开关 | localStorage |
| `update_available` | `true` / `false` | 是否有可用更新 | `update/status` |

> 调用方必须能处理**未知枚举取值**：未知的 `MIO_MOTION` 值按默认（关闭）处理。

## 限流与配额

- 本地单用户服务，**不限流、不配额**，无 429 响应。
- 客户端偏好读写**不产生 HTTP 请求**，不占用服务端配额。

## 超时与并发

- 建议客户端超时：`GET` 类 ≥ 5 s。
- 并发：偏好写入为单键覆盖，多标签页并发写以后写为准（last-write-wins），**无一致性风险**（偏好是幂等开关，非业务数据）。
- 长任务：不涉及。

## 文件上传与下载

本契约涉及的接口**不涉及文件上传或下载**（本节保留仅为完整性）。

## 安全与脱敏

- 客户端偏好**不上传服务端**，不含任何敏感信息。
- 响应不含本地绝对路径、不含凭据。
- 本次未放宽任何输入校验或访问控制。

## 兼容性与废弃策略

- **完全兼容**：所有 HTTP 接口的请求/响应/错误码/状态码均未变。
- 新增偏好为**可选**：无键时行为确定（动效关闭）。
- 偏好键若将来废弃，必须提供迁移逻辑（读取旧键 → 写新键 → 删旧键），不得直接删除。
