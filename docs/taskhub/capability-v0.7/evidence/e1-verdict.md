## 4. 建议裁决（待用户确认）

**R2**。理由：

1. E1 的两个信号方向相反，机械套用任一口径都会失真：0% 说「没人造假」，78% 说「没人留痕」。
2. 规划的默认战略本就是「自用 + 只做最便宜的可读性段落 + 不做 S1.1 硬门控」——R2 不是改道，是**用数据确认了默认战略**。
3. S1.1（Run 绑 commit+422）若按 R1/R3 处置，要么白做要么错做；按 R2 冻结，等待 E2 问A 最终确认。
4. E1 同时给出一个工程副产品结论：**若要求 Run 可归因，最低成本路径不是新增校验，而是存量纪律**（建 task-<id> 分支 / commit 带 task_id / 登记 deliverables）——零代码，纯流程约定。
