## 5. 通用请求头

| Header | 必填 | 类型 | 默认 | 说明 |
|--------|------|------|------|------|
| `Accept` | 否 | string | `application/json` | 期望 JSON；服务端恒返回 JSON |
| `Content-Type` | POST/PATCH 必填 | string | `application/json; charset=utf-8` | 本文件端点均为 GET，无请求体 |

- 无自定义追踪头；无请求头透传回响应的约定

## 6. 通用响应结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 业务字段 | 视端点 | 是 | `/healthz` 返回 JSON 数组；`/api/v1/tasks` 返回 JSON 数组（均属裸数组例外，见下） |
| `detail` | string/object | 错误时 | FastAPI `HTTPException` 标准错误体（错误路径唯一外壳） |

- 成功与失败互斥：成功无 `detail` 键；失败恒为 `{"detail": ...}`
- **裸数组例外（显式登记）**：`GET /healthz` 与 `GET /api/v1/tasks` 成功时直接返回 JSON 数组，不包 `{data:...}` 外壳
- 拆分影响：无——响应结构由 worker 内 app 决定，与进程拓扑无关

## 7. 统一错误码

| HTTP | 业务码 | 含义 | 触发条件 | 处理建议 |
|------|--------|------|---------|---------|
| 200 | OK | 成功 | 探活/列表查询完成 | 读业务字段 |
| 404 | ROUTE_NOT_FOUND | 路径不存在 | 拼错路径或误调未注册前缀 | 对照 §17 接口清单核对 |
| 422 | PARAM_INVALID | 参数校验失败 | query 参数越界（如 limit>200） | 修正请求参数 |
| 429 | RATE_LIMITED | 触发全局限流 | 短时间请求超阈值 | 按 `Retry-After`（若有）退避 |
| 500 | STORE_ERROR | 存储层异常 | worker 内 DB/文件读写失败 | 读 `detail`，重试或查数据文件 |

- 无 401/403（见 §4）；502/503 **不产生**——进程重启窗口内连接会被拒绝（connection refused），不是 HTTP 响应

## 11. 枚举全集

| 枚举 | 取值 | 含义 | 出现在哪些接口 |
|------|------|------|---------------|
| 任务 `state` | queued/claimed/running/retrying/completed/failed | 任务生命周期 | GET `/api/v1/tasks`（既有，不改） |
| 任务 `stage` | brainstorming/design/planning/ready/implementing/review/done/cancelled | 文档链阶段 | 同上（既有，不改） |

## 12. 幂等性与重试

| 接口 / 场景 | 幂等 | 幂等键 | 重试建议 |
|------------|------|--------|---------|
| GET `/healthz` | 是 | 不需要 | 连接被拒（重启窗口 ≤20s）时指数退避重试 1s/2s/4s，最多 3 次 |
| GET `/api/v1/tasks` | 是 | 不需要 | 同上 |

- 绝不可重试的状态码：422（先修参数）
- **拆分带来的可用性语义**：worker 崩溃 → supervisor 退避重启期间（≤20s，NFR-3）客户端会收到 **connection refused 而非 5xx**——调用方必须按「连接错误」处理，不可等价于服务端 500

## 13. 限流与配额

| 范围 | 阈值 | 窗口 | 超限响应 |
|------|------|------|---------|
| 本机调用方 | hub 全局 RateLimitMiddleware（既有策略，不变） | 既有 | 429（既有） |

- 拆分影响：无——限流中间件在 worker 内；supervisor 不参与限流
- 轮询建议：存活探测 ≥1s 间隔，避免触发 429

## 14. 超时与并发

- 服务端处理超时：无应用层超时（本地文件读取，毫秒级）——不变
- 建议客户端超时：5000ms
- 并发冲突：读端点无冲突；进程重启窗口内无排队机制（直接拒绝连接）
- 长任务处理：不适用（本任务无长任务端点）
- 拆分影响：无

## 15. 文件上传与下载

不涉及——本任务影响面内端点均无文件能力（整节无适用内容，保留章节以满足契约完整性）。

## 16. 安全与脱敏

## 18. 接口明细

### GET /healthz

- 用途：存活/就绪探针；supervisor/worker 拆分后「服务是否可对外」的唯一判据
- 权限：无（loopback）
- 幂等：是（GET 天然幂等）
- 副作用：无

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认 | 约束 | 说明 | 示例 |
|------|------|------|------|------|------|------|------|
| — | — | — | 否 | — | 无参数 | 存活探针不接受任何参数，直接 GET | `GET /healthz` |

#### 响应字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `[0]`（数组元素） | object | 是 | 服务信息对象（JSON 数组，非对象外壳——§6 裸数组例外） | `{"status":"ok"}` |
| （数组为空） | array | 否 | 未就绪时不返回空 200（未就绪为连接拒绝/启动中） | — |

#### 错误码

| HTTP | 业务码 | 含义 | 触发条件 | 处理建议 |
|------|--------|------|---------|---------|
| 200 | OK | 服务就绪 | worker 内 FastAPI 已启动并完成 lifespan | 视为可用 |
| — | CONNECTION_REFUSED | 服务不可达（非 HTTP 响应） | worker 崩溃重启窗口（≤20s）或 supervisor 退出 | 按 §12 退避重试，勿等价 500 |
| 404 | ROUTE_NOT_FOUND | 路径拼错 | 误写 `/api/v1/healthz` 等 | 用根路径 `/healthz` |

#### 示例

请求：

```bash
curl -s "http://127.0.0.1:48620/healthz"
```

响应（200，JSON 数组）：

```json
[{"status": "ok"}]
```

### GET /api/v1/tasks

- 用途：任务列表查询；生命周期流程中 `run_hub._probe_service` 以「HTTP 200 + 响应体以 `[` 开头」判定端口归属
- 权限：无（loopback）
- 幂等：是（GET 天然幂等）
- 副作用：无

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 默认 | 约束 | 说明 | 示例 |
|------|------|------|------|------|------|------|------|
| state | query | string | 否 | 不过滤 | 取值见 §11 | 按任务状态过滤 | completed |
| agent_type | query | string | 否 | 不过滤 | — | 只列匹配该 agent 类型的任务 | cli |

#### 响应字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `[i]`（数组元素） | object | 是 | 任务对象；至少含 `id`/`title`/`state`/`stage` | — |
| `[i].id` | string | 是 | 8 位十六进制任务 id | 516bd0c7 |
| `[i].title` | string | 是 | 任务标题 | hub 拆分 supervisor/worker… |
| `[i].state` | string | 是 | 枚举见 §11 | queued |
| `[i].stage` | string | 是 | 枚举见 §11 | design |

#### 错误码

| HTTP | 业务码 | 含义 | 触发条件 | 处理建议 |
|------|--------|------|---------|---------|
| 422 | PARAM_INVALID | 参数校验失败 | query 参数类型/取值非法 | 修正参数后重试 |
| 429 | RATE_LIMITED | 触发全局限流 | 超过既有 RateLimit 阈值 | 退避后重试 |
| 500 | STORE_ERROR | 存储层异常 | worker 内 DB 读取失败 | 读 `detail` 后重试 |
| — | CONNECTION_REFUSED | 服务不可达（非 HTTP 响应） | 重启窗口（≤20s） | 按 §12 退避重试 |

#### 示例

请求：

```bash
curl -s "http://127.0.0.1:48620/api/v1/tasks?state=queued"
```

响应（200，JSON 数组）：

```json
[{"id": "516bd0c7", "title": "hub 拆分 supervisor/worker 双进程架构", "state": "queued", "stage": "design"}]
```
