## 6 结论

| 项 | 裁定 |
|---|---|
| decision 硬闸 | **有效**：52.5% → 16.4%（CI 9.2–27.6） |
| signal | 仍 16.7%；需继续逐条分析 |
| result | 11.7%；列表碎片已明显减少 |
| 整体可用率 | 83.9%（规则辅助，非金标准） |
| 独立人工复核 | **未完成**；不能冻结阈值 |
| 生产重跑 | **不批准**（本轮未执行） |
| 新 exe | 继续阻塞 |

### 建议

1. 用 `review-sheet-p51b.tsv` 完成 2 名独立人工复核；至少覆盖 30 条中的 decision/result/signal/短片段。
2. 根据人工裁决修订 U1/U2：明确“短结论”最小谓词、`doc.review` 中测试计数应归 result 还是 decision。
3. signal 剩余 10 条逐条建立正反例；避免把“科学标题/发布标题”误杀。
4. 复核一致率达到可接受水平后，再决定是否生产重跑和阈值校准。
