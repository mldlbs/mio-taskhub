# 示例 Spec：任务中心增加「我的工作台」视图

## 背景
当前任务中心以看板为主，用户（agent）难以快速聚焦"我负责的进行中任务"。

## 目标
新增「我的工作台」聚合视图，按当前 agent 聚合其负责 / 认领的任务。

## 功能点
1. 顶部按 agent 维度分组，显示每个 agent 的进行中任务数
2. 展示最近一次心跳时间，自动标注离线态
3. 支持一键跳转任务详情抽屉

## 非目标
- 不做多用户权限隔离（本地单用户场景）
- 不接入外部日历系统

## 验收标准
- 工作台正确按 agent 聚合任务
- 点击任务可打开详情抽屉并查看 spec/plan
- 离线 agent 以灰色标记
