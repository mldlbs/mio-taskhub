# T3.2 / T3.3 条件性任务 defer 决策（G3 收口）

> 日期：2026-10-14 · 依据：`05` §11「条件性任务前置未触发前置置 ready」+ 各卡自身 defer 触发条件

## T3.2 · D2-b 门控协议化（条件性）

| 项 | 内容 |
|---|---|
| **前置条件** | T2.5 结论 **V1 成立**（门控 + ReadEvidence 改变 Agent 行为）+ 外部 ≥1 潜在用户可接入 |
| **实测前置** | T2.5（G2）判定 **V1 = 证据不足**（S2 方向正确但 n=1 ≪ 30；B 系列 V1 defer，真实 agent 不可用） |
| **触发结论** | **前置未满足 → defer**（非 cancel） |
| **卡自身约定** | "defer 触发：V1 证据不足 → 条件性 defer/cancel"（237dc133 description） |
| **判定依据** | `03` §7 D2「不成立」档 ②：无显著差异；且 V1 未证实前不得启动协议化 |
| **恢复条件** | 若后续 V1 对照实验（n≥30/组）得出 p<0.05 显著差异 + 外部 ≥1 接入 → 重新置 ready |
| **纪律** | V1 未证实前，对外**不得**称"经对照验证的差异"（`01` §4.3 禁止清单） |

## T3.3 · D3 可验证完成回执执行链测试（条件性）

| 项 | 内容 |
|---|---|
| **前置条件** | 外部 ≥1 个真实审查者（人 / CI / 产品）据回执作出决策 |
| **实测前置** | 外部真实使用者 = **0**（`01` E12：1 star / 0 fork / 无外部闭环）；无审查场景 |
| **触发结论** | **前置未满足 → defer**（非 cancel） |
| **卡自身约定** | "defer 触发：3 个月内 0 消费 → cancel"（59623dd6 description） |
| **判定依据** | `03` §7 D3「不成立」档：回执产出 3 个月内 0 消费 → 停止开发 |
| **恢复条件** | 出现 ≥1 真实审查场景（外部审查者据回执作决策）→ 重新置 ready |
| **纪律** | 原料（指纹/追溯/事件流）保留在库内不打包；不对外宣称"可验证回执" |

## 共同结论

- 两张条件性卡（T3.2/T3.3）**前置条件当前均未满足**，按 `05` §11 约定 **defer**（不 cancel，保留恢复路径）。
- **G3 无阻断**：T3.1/T3.4/T3.5/T3.6（非条件性）已全部完成；条件性卡 defer 不阻断 G4。
- 恢复条件均已写明（V1 证实 / 出现外部审查者），满足后可重新置 ready。
